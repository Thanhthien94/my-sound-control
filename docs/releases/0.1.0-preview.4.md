# My Sound Control 0.1.0 Preview 4 — per-application EQ

- Ten stereo EQ bands, 31 Hz–16 kHz, ±12 dB in 0.5 dB steps.
- Five tonal presets, custom per-app settings, bypass and reset.
- Preamp −24…0 dB, automatic headroom estimation, sample clipping protection and warning.
- Native vertical faders; 20 ms crossfade for EQ changes. Existing volume, mute, route and favorites remain compatible.

Open **EQ** beside an application. Enable both Mixer and EQ to hear processing. Presets change band gains; bypass keeps your settings. Automatic headroom can make boosted presets quieter. This is sample clipping protection, not a true-peak limiter. No named preset library, profile import/export, headphone correction or AU hosting yet.

## Validation

21 tests pass, including EQ center response checks at 44.1/48/96 kHz, flat/bypass identity, preamp, stereo isolation, mute, transitions, clipping, invalid values, concurrent publication and legacy preferences. Focused concurrent configuration/render testing passed under Thread Sanitizer. C sources pass `-Wall -Wextra -Werror` syntax checks.

On the development Mac, a quiet 1 kHz afplay fixture measured about −50 dBFS; setting the 1 kHz band to −6 dB with automatic headroom off changed the output meter to −56 dBFS. Bypass restored −50 dBFS. Mixer stop returned the fixture to original audio. Chrome audio was not controlled. These are pipeline/meter observations, not acoustic recordings or latency/listening certification.

Apple Silicon, macOS 15+. Ad-hoc signed, **not Apple-notarized**. See INSTALL.md. Existing hardware, sleep/wake and permission-on-clean-machine limitations remain in docs/validation.md.
