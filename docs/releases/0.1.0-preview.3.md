# My Sound Control 0.1.0 Preview 3

- Temporarily mute an application for 30 seconds, 1 minute or 2 minutes. See the countdown or unmute immediately; volume restores through the existing gain ramp when time expires.
- Timer state is not persisted. Disabling the mixer, changing its output, system sleep or quitting cancels the timer and returns the source to original audio.
- New Settings window with optional launch at login using macOS ServiceManagement. This is off by default and can be changed from the installed app in Applications. Audio capture still requires manually enabling Mixer.

## Validation

All 12 tests pass: eight DSP tests plus four deterministic tests for independent deadlines, exact expiry, replacing a deadline, cancellation/stop and invalid durations. Debug build, launch and strict signature checks passed. UI inspection confirmed the Settings window and disabled login control in the development copy; timed mute on a quiet afplay fixture displayed a countdown and −∞ dBFS. UI automation intermittently timed out, so uninterrupted end-to-end timing and the immediate-unmute action are not claimed as fully verified. Login registration, approval and actual login after reboot remain unverified; the setting was left off.

Apple Silicon, macOS 15+. Ad-hoc signed, **not Apple-notarized**. See INSTALL.md. EQ, boost, AU plugins, hotkeys, multi-device AirPlay and broader hardware/lifecycle validation remain future work.
