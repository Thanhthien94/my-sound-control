# My Sound Control 0.1.0 Preview 2

New original waveform/fader icon using SkyTruong orange, gold and green on a dark tile, in the same visual family as My Fan Control. The app bundle and mixer header now use this artwork.

Apple Silicon, macOS 15+. Audio features and limitations are unchanged from Preview 1: opt-in per-application volume/mute/output routing, hardware controls where available, and local preferences. No EQ, boost, Audio Unit plugins or multi-device AirPlay yet.

The preview is ad-hoc signed and **not Apple-notarized**. Follow INSTALL.md for installation. Compare downloads with SHA256SUMS.txt.

The icon was inspected at 16–256 pixels and on light/dark backgrounds. The local app build and signature verification passed. Audio behavior was not re-measured for this artwork-only update; prior observations and outstanding hardware checks are recorded in docs/validation.md.
